# 化合物—靶点来源与 GeneCards 核查

## 已核实的来源

主分析：v20241015/01_Get_compound.R。上游表：/home/data1/zhiyu/data/database/Metab.Gene/output/02_tidy_all.DB_tidy.csv。构建脚本：同目录上一级的 02_dbs_genes.R。

完整合并来源为 BindingDB、BATMAN-TCM 已知和预测靶点、Guide to PHARMACOLOGY、TCMSP。BATMAN 下载脚本实际指向 batman2.cloudna.cn；Meta_Bat 是本地字段标签，不是独立的 MetaBat 靶点数据库。

Gene_Value：已知类前三来源赋值100，BATMAN预测原分数乘100；>80 即预测原分数>0.80，并非统一实验置信度。TCMSP 的 Gene_value 大小写不同，Gene_Value 缺失，因此当前筛选排除了其靶点记录。TCMSP 仍提供中药成分。未修改分析代码或悄悄纳入被排除的记录。

根据上游数据重建 ZBM/XKC/XYT 的基因集分别为107/1094/2131，与论文存档逐基因完全相同。详见20号支持目录中的基因集核验及来源记录表。BindingDB构建代码未筛选亲和力或物种，已据实说明证据边界。
