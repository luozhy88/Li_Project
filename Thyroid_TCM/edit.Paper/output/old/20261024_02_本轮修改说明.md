# 2026-10-24 核心草药研究定位与后续优化说明

## 本轮采用的研究前提

根据作者说明，本研究从方剂中选取治疗甲状腺疾病的核心草药开展网络药理学，分析对象是选取的核心草药组合。研究不以完整临床处方逐味复现为目标。

上一版将正文整方介绍与实际分析输入直接对照，并据此认定“方剂组成有问题”，没有充分考虑这一选药设计。**本轮撤回该项判断，以及由此提出的处方核对、白毛夏枯草误纳和必须重算 XYT 的要求。** 本版以作者确认的核心草药选择为前提继续优化；这不等于另行完成了选药依据的文献系统验证。

本说明取代 `20261023_02_审查与修改报告` 中关于处方身份未确认、输入不一致及相应重算要求的意见。旧文件保留为历史版本，请优先阅读 `20261024` 文件。

1. **统一研究对象。** 标题、摘要、引言、方法、讨论、结论和图注均定义：XYT 指从小瘿汤处方背景中选取的核心草药组合。删除“provisional dataset”“unreconciled inventory”等表述，图中删除相应星号。
2. **恢复研究论文叙述。** 上一版较多使用核查报告式表述，本版围绕研究目的、实际分析方法、主要结果和生物学解释展开。处方核查过程不再充当研究发现。
3. **完善方法的可复核性。** 保留实际药材输入标签、CID 匹配、Gene_Value 筛选、疾病基因集合、BH 校正和 GO/KEGG 展示规则。没有凭空补写未执行的 OB/DL 筛选或假定数据库日期。
4. **强化结果而不过度推断。** 三组共同使用 12,987 个疾病相关基因；成分相关基因总数为 107、1,094、2,131，交集为 78、842、1,595。突出 XYT 的绝对覆盖范围，同时提供明确分母的比例 72.9%、77.0%、74.8%。
5. **重构讨论。** 重点讨论氧化应激、钙调控、甲状腺癌通路及共享成分；区分基因数、GeneRatio 和疗效。将 ZBM/XKC 与组合的比较解释为相互重叠的草药集合比较，不强行作为独立治疗组。
6. **明确后续验证路径。** 从成分表征、甲状腺癌细胞模型及非恶性对照，到靶点结合/功能实验和靶点扰动，说明计算结果如何转化为可验证的研究问题。未声称这些实验已经完成。
7. **保留已核实的统计和引文修正。** 保留正确的 Venn 集合数、BH P 值、GeneRatio 分母和参考文献编号/DOI。继续区分其他肿瘤或桥本甲状腺炎文献与本研究甲状腺癌机制证据。

## 独立于选药设计、仍需处理的内容

以下事项并不由“核心草药来自方剂”这一前提解决，因此没有恢复原稿中的过度结论：

- **受体身份：** [RCSB 4P5A](https://www.rcsb.org/structure/4P5A) 对应细菌 ThyX/PolB，不能作为人 POLB 的结构证据；该结果继续排除。
- **补充对接流程：** 现有本地日志显示使用 smina。6UNI 准备流程去除了 haem，自动定位参考也混合了多种非蛋白成分。9AYG 的定位参考尚不能证明对接到了经过验证的拮抗剂位点。因此保留数值为探索性输出，不以之声称“稳定结合”“抑制靶点”或整方疗效排名。
- **共享化合物：** β-sitosterol 是三个集合共有的同一化合物。相同配体和受体的重复对接差异不能归因为草药来源。
- **方法信息补全：** Gene_Value 的来源与含义、完整数据库来源、检索条件与日期、版本及 ID 映射处理仍需根据真实记录补充。未因缺少描述而否认现有草药网络分析结果。
- **作者信息：** 作者单位、具体贡献、研究地点和时间等仍以黄色提示保留，避免代作者编写不存在的信息。

对接问题的本地证据见 `20261024_03_support/20261024_docking_audit.csv`；较详细的既有证据保留在前一版报告的对接章节。本轮未进行新的对接或富集重算，也未重新开展网络药理学源数据库采集。
