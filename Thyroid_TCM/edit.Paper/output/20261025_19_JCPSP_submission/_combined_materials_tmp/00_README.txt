Supplementary material for the expert-reviewed manuscript (25 October 2026).
01–11: original network-pharmacology results and source checks. The docking audit includes excluded or unvalidated entries and does not establish human-target binding.
12–13: all GEO sample metadata and final paired patient–tissue observations. Blocks from the same patient and tissue type were averaged; 24 paired patients contributed 48 observations.
14–15: full differential-expression results and fixed-candidate results; logFC is log2(PTC/normal). DE_threshold requires BH-adjusted P<0.05 and absolute logFC>=1. Missing values for unmeasured candidates are not negative results.
16–17: six one-sided Fisher tests and candidate coverage. These are overlapping/nested sets, not independent herb-efficacy comparisons.
18–19: probe mapping summaries. 20–21: QC figures. 22: versions used for the NEW transcriptome analysis, not the original historical network-pharmacology environment.
23: explicit one-sided P values used in the manuscript, BH adjustment over six tests, conditional odds ratios and two-sided exact 95% confidence intervals. The separate two_sided_P_source column documents the CI-source calculation; it is not the prespecified test and is not used for manuscript FDR values.
24: Figure 4 of the revised manuscript. Colours overlay nested candidate sets and do not denote mutually exclusive membership.
Underlying public expression data: GSE60542 / GPL570, NCBI GEO. No analysis code is included in this package, in accordance with the authors' sharing decision.


Additional independent cohort GSE33630: files 25-38. Primary analysis uses 44 matched patients; 11 ATC and 6 unpaired tissues are excluded. Files 29-30 compare gene effects with GSE60542; file 31 reports exposure sensitivity, BH across 12 tests. Dataset-specific gene and Fisher P values are adjusted separately. Code is not included.
