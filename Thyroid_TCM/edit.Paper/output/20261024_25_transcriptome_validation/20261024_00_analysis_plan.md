# 独立公开转录组分析方案

在查看差异表达结果前固定：GSE60542，原发乳头状甲状腺癌与正常甲状腺；排除淋巴结、淋巴结转移和无法确认组织类型样本。核实病人编号，按病人×组织类型合并重复组织块；主分析使用成对病人并用limma控制病人。不能从表达数据宣称干预疗效或药物结合。

固定验证集：现有XYT1595、XKC842、ZBM78基因，不因表达结果改变集合。GPL570单基因映射探针；多探针按基因平均log2表达，无表达数据支持则不填补。以全测得基因BH校正差异分析，FDR<0.05且abs(log2FC)>=1定义差异基因。报告CYP3A4、CACNA1H、POLB不论显著性。

Fisher候选基因差异富集：主背景为所有测得基因；敏感性背景为历史疾病基因集与测得基因的交集；对三组集合检验校正。基因集嵌套，不当成独立验证或疗效比较。不根据显著性更换队列。检查PCA与表达分布，不能因样本不符合预期而剔除。

原分析代码保留本地以供审核，不随公开补充包发布。公开补充表包含样本清单、全量差异结果、基因集覆盖及检验结果；下载源、文件校验和、实际新分析环境版本保留。
