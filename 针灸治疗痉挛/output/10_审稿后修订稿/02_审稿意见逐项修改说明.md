# 审稿意见逐项修改说明

修订日期：2026年10月18日。旧稿及旧分析保留，不覆盖。

| 审稿问题 | 本轮修改 | 对结果的影响 |
| --- | --- | --- |
| 出版类型标签优先导致漏纳入 | 重新核查91条病例标签排除记录，补入4篇有系统观察/比较设计的研究 | 3篇进入神经性痉挛主分析，1篇面肌痉挛研究仅进入广义集合 |
| 研究范围混杂 | 将神经性痉挛作为主分析，其他痉挛领域用于范围敏感性分析 | 146篇主分析；173篇广义集合，其中27篇不进入主分析 |
| 信息不足被当作不合格 | 单列16条信息不足记录，415条为明确排除 | 流程图分开报告，不以题名或类型标签猜测设计 |
| 动物和人体研究误分 | 纠正3篇动物实验、1篇回顾性病例系列及1篇非随机干针研究；1篇设计冲突单列 | 主分析61篇综述、43篇随机临床研究、19篇其他人体研究、19篇动物实验、2篇二次分析、1篇共识、1篇冲突 |
| 背景治疗规则不清 | 明确针刺作为主动评价方案、联合方案及单纯背景清单的区别 | 联合方案不被用于推断针刺独立疗效 |
| 创新性不足 | 新增干针专题×疾病×设计交叉表及图，补充直接竞争研究 | 34篇干针专题与112篇其他/综合专题比较，明确为出版物构成比较 |
| 国家推断规则过宽 | 用明确中国机构白名单替代通用专业名称推断 | 保留逐地址映射，主分析可定位国家/地区143篇 |
| 时间趋势推断过强 | 删除线性拟合、R²、自定义突现模型和时期显著性推断 | 保留实际年度数量、关键词覆盖、归一化热图与时期构成 |
| 设计词影响关键词解释 | 补充删除设计词的敏感性分析 | 24个节点、92条连线，模块度0.130；仍不解释为独立成熟热点 |
| 图号及正文不一致 | 全部图表重算，并按首次出现顺序编号 | 7张表、11幅图全部嵌入正文 |
| 写作像项目过程报告 | 重写摘要、引言研究问题、讨论和结论，精简操作性说明 | 数据准备过程移入补充说明；正文围绕神经性痉挛及专题差异 |
| 可复现不等于筛选正确 | 分开报告数值核验和研究者复核局限 | 不声称双人独立筛选、完整全文复核、风险偏倚评价或录用保证 |

本轮交付为依据现有材料完成重分析后的中文修订稿，不是已获人类独立双筛的版本。无法取得的材料、单库英文范围、作者消歧和干针专题分类的局限已保留在正文，未通过删除局限或强化结论掩盖。
