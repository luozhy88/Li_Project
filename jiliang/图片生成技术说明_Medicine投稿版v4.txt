一、总体结论
--------------------------------------------------------------------------------
Word 报告内所有图片（27 张嵌入 PNG，投稿 JPG 组 18 张）全部由 Python 脚本生成，
不涉及 CiteSpace / VOSviewer / GraphPad 等软件出图。分析与绘图均在项目自带虚拟环境
.venv 中完成（Python 3.13）。Word 文档本身由 python-docx 拼接图片与文字生成。

五、论文 Methods 可直接使用的英文段落
--------------------------------------------------------------------------------
Data parsing, deduplication, and descriptive statistics were performed with Python
3.13 and pandas. All figures were generated programmatically with the Python
libraries matplotlib (version >= 3.8) and seaborn (version >= 0.13); network
visualizations (keyword co-occurrence, author and country collaboration) were
constructed with NetworkX, and keyword word clouds with the wordcloud package.
The worldwide distribution map was drawn with matplotlib using Natural Earth
country boundaries (1:110 m). Tabular figures were rendered with the Python
Imaging Library (Pillow). A color-blind-safe palette (Wong, Nature Methods 2011)
was used for all multi-category figures, which were exported at 300 dpi in PNG
format and converted to JPEG for submission. The final figures and tables were
assembled into a Word document with python-docx.
